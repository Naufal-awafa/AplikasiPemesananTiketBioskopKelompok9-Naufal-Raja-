Taruh file logo kamu di folder ini dengan salah satu nama berikut:
  logo.svg   (paling direkomendasikan - tajam di semua ukuran layar)
  logo.png
  logo.webp
  logo.jpg / logo.jpeg

Begitu file dengan salah satu nama di atas ada di folder ini, situs akan
OTOMATIS memakainya di:
  - Logo navbar (pojok kiri atas, semua halaman)
  - Logo animasi loading (preloader)
  - Logo di footer
  - Favicon (ikon tab browser)

Tidak perlu edit kode apapun. Kalau file ini dihapus/belum ada, situs akan
otomatis kembali memakai ikon emoji clapperboard sebagai fallback.
